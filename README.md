# Новостной дайджест — автоматический мониторинг и аналитика

Сервис собирает новости из 100+ RSS-лент и Telegram-каналов, анализирует их с помощью **Google Gemini API**, структурирует по категориям (геополитика, экономика, бизнес, технологии, энергетика, безопасность, PR) и регионам (мир/Россия), а затем отправляет **краткий дайджест в Telegram** по расписанию (5 раз в день).

Проект работает на **GitHub Actions** с внешним триггером от **cron-job.org** — это обеспечивает стабильность запусков без задержек и сбоев встроенного cron.

---

## Возможности

- **Парсинг > 100 RSS-лент** (включая Google News fallback для сайтов без RSS) + **6 Telegram-каналов**.
- **Асинхронный сбор** (параллельные запросы, кеширование) — быстрый и бережливый.
- **Двухуровневая дедупликация**: программная (сравнение похожести заголовков) + семантическая (передача недавних заголовков в промпт Gemini).
- **Анализ Gemini** (модель `gemini-3.6-flash`):
  - Классификация по 7 категориям.
  - Выделение региона (мир/Россия).
  - Генерация **развёрнутого резюме** (2–4 предложения с причинами и следствиями).
- **Формирование HTML-дайджеста** с разделами «Мир», «Россия», «PR в мире», «PR в России».
- **Отправка в Telegram** через `sendRichMessage` (HTML-форматирование, поддержка ссылок, до 32768 символов).
- **Защита от потери**: если отправка не удалась, дайджест сохраняется и повторно отправляется при следующем запуске.
- **Мониторинг**:
  - Метрики каждого прогона в `metrics.jsonl` (время по этапам, статусы, количество новостей, ошибки).
  - Интерактивный дашборд `dashboard.html` с графиками, таблицами и состоянием источников.
  - Алерты при сбоях (Telegram + опционально вебхук).
- **Автоматическая очистка мёртвых источников** — еженедельная проверка здоровья RSS/Telegram, создание `stale_sources.json` для исключения неработающих лент.
- **Гибкая конфигурация** через `config.json` — все параметры вынесены из кода.

## Технологии

- **Язык:** Python 3.10+
- **Библиотеки:** `aiohttp`, `asyncio`, `requests`, `feedparser`, `BeautifulSoup4`, `diskcache`, `json`, `re`, `time`, `datetime`
- **AI:** Google Gemini API (gemini-3.6-flash)
- **CI/CD:** GitHub Actions (два workflow: основной и проверка здоровья)
- **Внешний планировщик:** cron-job.org (HTTP-триггеры workflow_dispatch)
- **Визуализация:** Chart.js (дашборд)
